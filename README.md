# VibraSafe: Biometric Hearing & Safety Wearable

VibraSafe (formerly Guardian Cuff) is a bilateral, fashion-forward ear cuff engineered for Deaf and Hard-of-Hearing individuals. It converts ambient environmental sound (sirens, smoke alarms, vehicle approach) into intuitive, 360-degree directional touch.

This repository contains a Next.js monorepo featuring two core applications:

### 1. The Marketing & Science Platform (`/marketing-website`)
A high-performance, Apple-style luxury landing page built to present the scientific validation and hardware architecture of VibraSafe. 
* **Tech Stack:** Next.js 14, React, Tailwind CSS, Framer Motion.
* **Features:** Scroll-driven video parallax, interactive 3D color studio, and responsive Bento Grid layouts.

### 2. The Companion Safety App (`/safety-app`)
A progressive web application that acts as the control center for the wearable hardware.
* **Tech Stack:** Next.js, React Three Fiber (3D rendering), Zustand (State Management).
* **Features:** Real-time 3D device visualizer, active safety programs (Street, Focus, Sleep), and an interactive acoustic-to-tactile simulator.
